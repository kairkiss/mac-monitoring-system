Remote Access

Securely access your monitoring system from the internet via Cloudflare Tunnel.

🔒 Double protection: Cloudflare Access + App Login
Cloudflare Setup Wizard
1
Install cloudflared
Install the Cloudflare Tunnel client
brew install cloudflared
2
Login to Cloudflare
Authenticate with your Cloudflare account
cloudflared tunnel login
3
Create Tunnel
Create a named tunnel
cloudflared tunnel create mac-monitor
4
Configure DNS
Point your domain to the tunnel
cloudflared tunnel route dns mac-monitor monitor.yourdomain.com
5
Start Tunnel
Start tunneling traffic to local web server
cloudflared tunnel run --url http://127.0.0.1:8765 mac-monitor
