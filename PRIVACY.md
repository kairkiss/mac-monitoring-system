# Privacy Policy

## Camera Access

Mac监控系统 requires camera access to provide real-time preview, photo capture, and video recording features. Camera permission is requested on first launch.

## Local Storage

All photos and videos are saved locally on your Mac at:

```
~/Library/Application Support/CameraApp/Photos/
~/Library/Application Support/CameraApp/Videos/
```

No data is uploaded to any server by default.

## Telegram Push

If you configure and enable Telegram push:

- Photos captured by automation tasks can be sent to your own Telegram chat via your own Bot Token
- The Bot Token and Chat ID are stored locally in macOS UserDefaults
- No data is sent to the developer or any third-party server
- You can disable Telegram push at any time in Settings

## Automation

Scheduled capture tasks run locally on your Mac. You can enable or disable automation at any time from the menu bar or the main window.

## No Tracking

This app does not collect analytics, telemetry, or any user data. There are no third-party SDKs or tracking frameworks.

## Open Source

The full source code is available on GitHub for audit.
